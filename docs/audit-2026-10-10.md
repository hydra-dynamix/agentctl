# Library audit — 2026-10-10

Scope: current library and CLI, including the pre-existing uncommitted native
OpenRouter provider and sandbox configuration changes. The operator authorized
ownership, repairs, validation, and a commit. No paid provider requests were made.

## Findings and repairs

| Priority | Finding | Repair and evidence |
| --- | --- | --- |
| P1 | Linux subreaper cleanup signalled all children of the host and used `waitpid(-1)`, interfering with unrelated work and concurrent captures. | Scope cleanup by process group and an inherited capture marker; reap only owned PIDs; register every active process group for signal forwarding. Regression preserves an unrelated child and a second capture while the first exits. Existing escaped-session and signal-forwarding tests pass. |
| P1 | Windows had no process-tree ownership or descendant cleanup. | Start commands suspended, assign them to a kill-on-close Job Object, then resume them. Regression verifies a grandchild is terminated after its parent exits. |
| P1 | Windows detached supervisors inherited caller output handles, keeping a tool caller waiting until the job finished. | Create the supervisor without inherited handles or a visible console; initialize its log inside the supervisor. A live-job regression verifies the launch returns while the job is still running. |
| P2 | Job liveness invoked Unix `kill`, causing live Windows jobs to be labelled stale. | Use native process-handle liveness checks on Windows and `kill(pid, 0)` on Unix. |
| P2 | Failed foreground iterations discarded all reports, emitted no JSON, and returned generic exit code 1. | Preserve prior reports and the failed report, stop iterations, and return the actual failed exit code. Regression fails iteration two with code 7 and checks both reports and the raw-log path. |
| P2 | External summarizers collected arbitrary output and ignored preview-line limits. | Use managed bounded capture and enforce the configured preview-line count. Regression emits 100,000 summary lines. |
| P2 | Status loaded entire logs to return a tail; raw-log viewing repeatedly loaded whole files and rejected non-UTF-8 output. | Read at most a 16 KiB tail for status; stream raw logs by byte position. Regression exercises a 1 MiB line followed by invalid UTF-8. |
| P2 | Detached job IDs collided for repeated calls in one process within the same second. | Include nanoseconds and a process-local counter; regression checks 1,000 generated IDs. |
| P2 | Native Windows usage required HOME, and two CLI tests required an unavailable Unix shell. | Fall back to USERPROFILE and use Python test commands on both platforms. |

Embedders now have `launch_detached_with_executable` so they can explicitly supply
the agentctl supervisor binary instead of re-executing their own application.
The existing self-reexecution API is documented. Existing provider support is
included in this commit, with local HTTP fixture tests of request authentication,
model/prompt serialization, returned content, and the CLI integration.

## Verification limits

Provider tests use a local server; live OpenRouter credentials, billing, and remote
model availability were not exercised. Hosted GitHub Actions has not run locally.
macOS was not tested. Linux cleanup remains cooperative lifecycle management:
a descendant that both abandons its process group and removes its ownership
environment marker cannot reliably be attributed to its originating capture.
The same attribution limit applies to escaped descendants that exit before
cleanup can observe their environment; their zombie records lack that marker.
This process manager is not a containment boundary for hostile commands.
